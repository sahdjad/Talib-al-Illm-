# Übersetzungen

Noch leer. Hier sammeln wir künftig Buchübersetzungen (Originaltext, Übersetzung, Anmerkungen).

Sobald ein konkretes Buch/Text feststeht, bitte den Titel, die Quelle und das gewünschte Format
(z. B. Kapitel für Kapitel als Markdown, zweisprachig nebeneinander) mitteilen, dann wird hier eine
passende Struktur angelegt.
