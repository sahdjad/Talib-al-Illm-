# Talib al-Ilm

Sammlung rund um die Koranschule (DBZ Bildungszentrum e.V.) und begleitende Wissensarbeit:
Unterrichts-/Gesprächsprotokolle, Klassenlisten und (perspektivisch) Buchübersetzungen.

Für den technischen Teil (die eigentliche Schulverwaltungs-App) siehe das separate Repository
[DBZ-App](https://github.com/sahdjad/DBZ-App) – dort bleibt alles, was direkt die App/den Code betrifft
(inkl. der App-Auswertung aus den Lehrerbesprechungen). Hier läuft alles andere rund um die Koranschule
zusammen: Protokolle, Klassenlisten, Vorbereitungen und künftig Übersetzungen.

## Struktur

- **`protokolle/`** – Gesprächs-/Meeting-Protokolle der Lehrkräfte (z. B. Unterrichtsplanung,
  Klassenorganisation) sowie zugehörige Klassenlisten, jeweils als Markdown und – wo erstellt – als
  formatiertes PDF.
- **`uebersetzungen/`** – Buchübersetzungen/-materialien, je Buch ein eigener Unterordner.

## Aktueller Stand

  Zeitstruktur, Regeln, Aufgabenliste)
- `protokolle/2026-09_klassenliste-klasse3.md` – Klassenliste Klasse 3 mit Status (Grün/Rot/Probezeit),
  korrigiert und alphabetisch sortiert

  Protokoll, Klassenliste) im DEEN-Bildungszentrum-Design
- `uebersetzungen/durus-al-muhimmah/` – Ad-Durus al-Muhimmah li ʿĀmmat al-Ummah (Ibn Bāz): arabisch/
  deutsche und englische Ausgabe sowie die vollständige Erläuterung (Šarḥ) von Scheich Hayṯam
  Sarḥān, alle 18 Lektionen, als Original-PDF und als durchsuchbares Markdown
